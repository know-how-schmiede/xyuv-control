# Bildvorlagen

Logo und Banner wurden mit dem integrierten Imagegen-Werkzeug erstellt.
Das Logo hat einen transparenten Hintergrund. Das Banner nutzt das Logo als
Gestaltungsreferenz. Die Illustration ist ein Projektmotiv, kein Anschlussplan
oder maßstäblicher Bauplan.

## Logo: xyuv-control-logo.png

```text
Use case: logo-brand. Create a polished original compact square logo mark for xyuv-control, an open source four-axis X/Y/U/V CNC hot-wire foam cutter controller. Transparent background. Vector-like crisp geometric design: two opposed upright CNC carriage shapes connected by one fine orange hot wire, abstract coordinated-axis geometry, a small cut foam profile suggested by negative space. Strong simple silhouette readable at 96 pixels. Restrained technical aesthetic, charcoal structural strokes with teal accents and warm orange wire. No lettering, no words, no gradients, no shadows, no mockup, no watermark. Centered mark with generous transparent padding. This is the final project logo asset.
```

## Banner: xyuv-control-banner.png

Referenzbild: `xyuv-control-logo.png`.

```text
Use case: logo-brand. Asset type: wide project README banner, approximately 3:1 landscape composition. Input image 1 is the reference project logo; preserve its distinctive two opposed CNC towers, teal rails, orange connecting hot wire and white foam airfoil in the banner illustration. Create a matching polished technical banner for the open source project xyuv-control. Dark charcoal navy background with very subtle engineering grid, restrained teal accents, warm orange wire. Left half: large perfectly legible exact lowercase project name 'xyuv-control' in clean bold modern sans-serif. Beneath it, exact small text 'X / Y / U / V' and '4-axis hot-wire CNC'. Right half: clean simplified illustration based on reference logo, all within frame, generous margins. Balanced professional open source engineering identity, flat crisp graphical illustration, no photorealism, no decorative circuitry, no extra words, no watermark. Final ready-to-use banner.
```
