# xyuv-control

![xyuv-control – Vierachsensteuerung für Heißdraht-Schaumschneider](docs/images/xyuv-control-banner.png)

4-axis X/Y/U/V CNC controller for hot-wire foam cutters based on Raspberry Pi Pico 2 W, MicroPython and G-code
